# Security policy

## Supported versions

Pre-`1.0`: fixes land on the latest release only.

## Reporting an issue

Open an issue on [GitHub](https://github.com/iMazed/laravel-helpscout-sidebar/issues).

## Security model

The package's threat model (the signature trust boundary, what counts as attacker-controlled, and the properties the test suite pins) is documented in [docs/security.md](docs/security.md).
